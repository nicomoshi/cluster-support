Cluster Support

Cluster connects to your own Hermes Agent gateway. If you need help, email rodolfo.arg.ce@gmail.com.

Connect Hermes

  1. Install Hermes on the Mac or server you want Cluster to use.
  2. Run hermes setup --portal.
  3. Copy the API key from ~/.hermes/.env.
  4. Start the gateway with hermes gateway.
  5. Open Cluster and tap Connect Hermes.

Recommended Private Access

For iPhone access outside the Hermes host, use a private network such as Tailscale and expose Hermes under /hermes.

Troubleshooting

  • Check that the Hermes gateway is running and reachable from the device.
  • Confirm that the API key in Cluster matches the key on the Hermes host.
  • If you use a reverse proxy, confirm the path and TLS settings in the Advanced section.
